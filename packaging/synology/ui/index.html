RemoteDesktop

The relay is installed on this NAS. Install the Windows clients on the PCs you want to control and control from.

Host (the PC you want to control)

Run this on the machine that should be remote-controlled. It shows a session ID and password to hand to the viewer.

Download Host (Windows)

Viewer (the PC you control from)

Run this on the machine you sit at. Enter the relay address, session ID and password, or save targets in the address book.

Download Viewer (Windows)

Relay address to enter in the clients

Use your NAS's public address and the relay port, for example myname.synology.me:9945.

Reminder: forward the relay TCP port on your router to the NAS, and allow it in the DSM firewall (Control Panel → Security → Firewall). The traffic is end-to-end encrypted, so the open port only exposes an opaque rendezvous service; without the session password no pairing is possible.
