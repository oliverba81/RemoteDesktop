RemoteDesktop

The relay is installed on this NAS. Install the Windows app on every PC involved — when it starts, you choose whether that machine is shared (Host) or controls another one (Viewer).

RemoteDesktop app (Windows)

One program for both roles. On the PC to be controlled pick Share this PC (Host) — it shows a session ID and password. On the PC you sit at pick Control another PC (Viewer) and enter those credentials or use the address book. Shortcuts can skip the chooser with --host or --viewer.

Download RemoteDesktop (Windows)

Relay address to enter in the clients

Use your NAS's public address and the relay port, for example myname.synology.me:9945.

Reminder: forward the relay TCP port on your router to the NAS, and allow it in the DSM firewall (Control Panel → Security → Firewall). The traffic is end-to-end encrypted, so the open port only exposes an opaque rendezvous service; without the session password no pairing is possible.
